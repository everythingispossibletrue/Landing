# Waymark Career

Статический сайт Дарьи Хамидуллиной: карьерные консультации и HR-консалтинг. Три языковые версии: русский `/`, английский `/en/`, казахский `/kk/`.

Для публикации достаточно содержимого `dist/`. Серверу не нужны Node.js, Python или установка зависимостей.

## Структура проекта

| Файл или каталог | Назначение |
| --- | --- |
| `src/pages/ru.html`, `en.html`, `kk.html` | Тексты и HTML-разметка каждой языковой версии |
| `src/templates/document.html` | Общая оболочка HTML-документа и счётчик Яндекс Метрики |
| `src/site.css` | Стили, сгруппированные по компонентам |
| `src/site.js` | Меню, прокрутка, анимации, вкладки услуг, карусель отзывов и поддержка старых языковых ссылок |
| `src/site-config.json` | Адрес сайта, контакты и SEO-метаданные |
| `src/telegram-messages.json` | Готовые сообщения для кнопок Telegram |
| `src/portrait-cutout.png` | Фото Дарьи с прозрачным фоном для первого экрана |
| `src/hero.jpg`, `src/favicon.svg` | Картинка для превью в соцсетях и иконка сайта |
| `scripts/build-seo.py` | Сборка страниц, SEO-файлов и архива |
| `scripts/structured_data.py` | Schema.org-разметка из видимых карточек услуг |
| `scripts/html_document.py` | Чтение структуры HTML для разметки услуг |
| `scripts/check-seo.py` | Проверка страниц, ссылок, SEO-файлов и архива |
| `scripts/check-interactions.cjs` | Проверки поведения интерфейса |
| `scripts/check-project.cjs` | Проверки корневого перехода и доступности разметки |
| `scripts/test_build.py` | Регрессионные проверки сборки |

## Сборка

Нужен Python 3.9 или новее, дополнительных Python-пакетов нет:

```sh
python3 scripts/build-seo.py
python3 scripts/check-seo.py
```

Сборщик создаёт `dist/`, обновляет `waymark-production.zip` и копии `robots.txt`/`sitemap.xml` в `deployment-extras/`.

При смене домена укажите `site_url` в `src/site-config.json` или передайте его для сборки и проверки:

```sh
SITE_URL=https://example.com python3 scripts/build-seo.py
SITE_URL=https://example.com python3 scripts/check-seo.py
```

## Работа с контентом

Редактируйте HTML нужного языка в `src/pages/`. Названия и цены услуг автоматически попадают в Schema.org из этих же карточек. Заголовки страниц и описания для поиска находятся в `src/site-config.json`.

Ссылки вида `${telegram_header}` — явные подстановки сборщика. Соответствующий текст сообщения лежит в `src/telegram-messages.json`; сборщик сам кодирует его в URL. Это позволяет читать и менять сообщения без длинных последовательностей `%D0%...` в HTML. Токены `${locale_ru}`, `${locale_en}`, `${locale_kk}` и `${asset_prefix}` задают относительные ссылки и пути к изображениям; они рассчитываются из конфигурации. Обычные знаки `$` в тексте не требуют экранирования.

Услуги разделены на вкладки «Для специалистов» и «Для бизнеса». Ссылки на `#business` или `#service-4` сами открывают нужную вкладку; без JavaScript обе вкладки показаны подряд.

Секция отзывов `#reviews` скрыта атрибутом `hidden`: в ней пока тестовые тексты (`data-placeholder="reviews"`). Чтобы показать её, замените тексты реальными отзывами во всех трёх языках, удалите `hidden` и `data-placeholder`, верните пункт меню `#reviews` перед «Вопросами» и поменяйте номер у FAQ с «06» на «07». Если показать секцию с тестовыми текстами, сборщик выведет предупреждение. Отзывы не попадают в Schema.org.

После изменений выполните сборку и проверки. При изменении общей разметки обновите все три языка.

## Форматирование и тесты интерфейса

Инструменты разработки используют Node.js 22.22.2+, 24.15+ или 26+. Версии зависимостей зафиксированы в `package-lock.json`.

```sh
npm ci
npm run format
npm test
```

`npm test` сначала пересобирает сайт, затем проверяет сборку, SEO и поведение меню, прокрутки, анимаций, языковых ссылок и якорей. jsdom моделирует DOM; размеры элементов и завершение анимаций в тестах заданы явно. Эти проверки не заменяют визуальную проверку в браузере.

## Локальный просмотр

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте `http://127.0.0.1:4173/`. Дополнительная проверка HTTP-маршрутов:

```sh
python3 scripts/check-seo.py --base-url http://127.0.0.1:4173/
```

## Публикация

GitHub Pages публикуется workflow `.github/workflows/pages.yml` при каждом push в `main`: он собирает сайт и выкладывает содержимое `dist/` в корень, поэтому сайт открывается по `https://everythingispossibletrue.github.io/Landing/`. Старый адрес `/Landing/dist/` переадресует на корень. В настройках репозитория должно быть выбрано Settings → Pages → Build and deployment → Source: **GitHub Actions**.

Для другого хостинга загрузите всё содержимое `dist/` или распакуйте `waymark-production.zip` в корень сайта, сохранив каталоги `en/` и `kk/`. Файлы в корне репозитория служат для разработки и не входят в публикацию.

Настройки Sites находятся в `.openai/hosting.json`. Доступ к текущей публикации оставлен закрытым по указанию владельца. Техническая SEO-подготовка выполнена, но индексация требует публичного доступа. Подробнее — в [SEO_REVIEW.md](SEO_REVIEW.md).
