## Проверки

- Полная команда `npm test`: успешная сборка, статические SEO-проверки RU/EN/KK, **14 Python-тестов и 25 Node.js-тестов**.
- Проверены canonical/hreflang, sitemap, robots, десять услуг Schema.org на каждом языке, локальные ссылки, ID, изображения и побайтовое соответствие ZIP содержимому `dist/`.
- Регрессионные тесты сборки используют временные фикстуры и намеренные ошибки, включая отказ замены архива.
- Prettier: все исходники HTML/CSS/JavaScript/JSON соответствуют конфигурации проекта.
- JavaScript и Python проходят синтаксическую проверку; CSS разбирается jsdom без ошибок (354 верхнеуровневых правила).
- `git diff --check`: без ошибок пробелов.

Для запуска тестов после установки зависимостей: `npm ci`, затем `npm test`. В текущем окружении использована уже установленная копия jsdom через `NODE_PATH`; сетевые зависимости повторно не загружались.

## Что остаётся непроверенным

Подключённых браузеров нет: Browser вернул пустой список. Поэтому не выполнены скриншоты и реальные замеры переполнения в Chrome/Safari/Firefox, на телефонах, при текстовом увеличении и смене ориентации. jsdom проверяет структуру, события и разбор CSS; геометрия и завершение анимаций в его тестах моделируются.
