# Waymark Career

Полностью статический сайт Дарьи Хамидуллиной: карьерные консультации и HR-консалтинг. Сборка не нужна. HTML, CSS, JavaScript и изображения публикуются прямо из корня репозитория.

## Страницы и файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Русская главная страница |
| `en/index.html` | Английская версия |
| `kk/index.html` | Казахская версия |
| `site.css` | Общие стили |
| `site.js` | Меню, вкладки услуг, языковые ссылки, карусель и анимации |
| `portrait-cutout.png` | Текущий портрет с прозрачным фоном |
| `hero.jpg`, `favicon.svg` | Превью для соцсетей и иконка |
| `portrait.jpg`, `portrait.webp` | Сохранённые исходные варианты портрета |
| `robots.txt`, `sitemap.xml` | Файлы для поисковых систем |
| `.nojekyll` | Отключение обработки сайта Jekyll на GitHub Pages |
| `scripts/check-*.cjs` | Проверки готового сайта; ничего не генерируют |

## Редактирование

Меняйте страницы напрямую. Общие тексты и разметку обновляйте во всех трёх языках. Ссылки относительные и работают при размещении в `/Landing/`. Метаописания и Schema.org находятся в `<head>` каждой страницы. После изменения услуг обновите соответствующую Schema.org-разметку. При смене домена обновите canonical, hreflang, Open Graph, Schema.org, `robots.txt` и `sitemap.xml`.

Отзывы пока скрыты: в секции `#reviews` находятся тестовые тексты. Показывайте её только после замены на реальные отзывы.

## Просмотр

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173/`. Python здесь только раздаёт файлы; можно использовать любой статический сервер.

## Проверки для разработки

```sh
npm ci
npm test
```

Node.js и зависимости нужны только для проверок. Для работы сайта и публикации они не нужны. Тесты проверяют локальные ссылки, изображения, языковые версии, метаданные и взаимодействия. Они не заменяют визуальную проверку в браузере.

## Публикация

Адрес: https://everythingispossibletrue.github.io/Landing/

В GitHub Pages можно публиковать `main` → `/ (root)` или использовать workflow `.github/workflows/pages.yml`, который загружает готовые файлы из корня без шага сборки. В обоих случаях открывается одна и та же статическая главная страница. Каталога `dist` и переадресации на него больше нет.

Для другого хостинга достаточно `index.html`, папок `en/`, `kk/`, `site.css`, `site.js`, изображений, `favicon.svg`, `robots.txt` и `sitemap.xml`. Папки `scripts/`, `.github/`, `.idea/` и `node_modules/` серверу не нужны.

Документы `CODE_REVIEW.md`, `RELEASE_REVIEW.md` и `SEO_REVIEW.md` описывают более раннюю версию проекта и сохранены как история.
